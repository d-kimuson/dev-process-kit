Agent が書く単一 HTML を、人がレビューして Agent に返す

dev-process-kit は、Agent に生成させる HTML Artifact（プロトタイプ、ストーリーマップ、イベントストーミングなど）に 共通の構造とレビューの仕組みを与えるフレームワークです。ビルド不要で、script タグ 1 つで読み込めます。

  1. 書く Agent がテンプレートに沿って単一 HTML を書く。中身のデータは JSON で HTML に埋め込む。
  2. レビューする 人がブラウザ上でコメントや構造の変更を残す。下書きは LocalStorage に残り、再読込しても消えない。
  3. 返す Copy brief で変更要求を Agent に渡し、HTML を作り直してもらう。反映済みの下書きは自動で消える。

Templates

開発プロセスの成果物ごとのテンプレートです。Agent はデータを書くだけで、画面とレビューはテンプレートが用意します。

Event Storming

artifact-event-storming

ドメインイベントを時系列に並べ、コマンド・集約・ポリシーとの因果をたどる。

User Story Mapping

artifact-usm

Activity と Step の背骨の下に、リリースごとにユーザーストーリーを並べる。

Example Mapping

artifact-example-mapping

ストーリーごとにルール・具体例・疑問を積み、要件の抜けを洗い出す。

Visually Grill

artifact-grill

設計を図で示しながら質問を投げ、回答とコメントを Agent に返す。

UX Prototype

artifact-prototype

画面の流れをストーリーとステップに分けて並べ、プレビューで確かめる。

Plain

artifact-plain

ヘッダーとレビューだけを持ち、中身は自由に書く。

Patterns

テンプレートに当たらない資料は、Plain に図のコンポーネントと自由な HTML を組み合わせて作ります。

Components

Plain やテンプレートの中に置ける図のコンポーネントです。

使い方

バージョンを固定した URL から、使うテンプレートの entry を 1 つ読み込みます。

<script type="module"
  src="https://dev-process-kit.biz-km.workers.dev/dev-process-kit@debug/templates/prototype.js"></script>

<artifact-prototype storage-key="my-flow">
  <script type="application/json">{ "activities": [] }</script>
</artifact-prototype>

図を使うときは components.js も読み込みます（全部入りは index.js）。

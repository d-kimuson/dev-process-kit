dev-process-kit

Agent が書く HTML のためのデザインシステム

  • Agent にとって解釈・記載しやすいデータ構造
  • 人間にとって見やすい図形や規定となるデザインシステム
  • Agent と人間が共通理解を構成するための標準化されたプロセス

これらを統合的に提供する Web Components のセットです。そのまま利用できる USM, ERD などの図形や、デザインシステムを用いて構成したカスタム図形をベースに一貫したループを実現します。

  1. 人間に適した認知モデルで描く

    Agent が USM / ERD などの認知モデルに沿って、データを JSON で埋め込んだ HTML を書く。

  2. レビューする

    人がブラウザ上で図を操作し、コメントと変更要求を残す。下書きは LocalStorage に残り、再読込しても消えない。

  3. 反映する

    「変更・コメントをコピー」（または Claude に送る）で変更要求を Agent に渡し、HTML を更新してもらう。反映済みの下書きは自動で消える。

dev-process-kit はポン出しの HTML に最適化されており、ビルド不要で script タグ読み込みで利用可能。トークン、CSS atoms、コンポーネント、ビュー、ボードを組み合わせて、1 枚のページをすぐに組み立てられます。

Getting Started

Agent にスキルを渡すか、Claude Code のプラグインとして入れるか、CDN から直接読み込んで試せます。 

npx skills add d-kimuson/dev-process-kit

# then ask the agent:
Create a USM for this product.
Follow https://raw.githubusercontent.com/d-kimuson/dev-process-kit/main/skills/dev-process-kit/SKILL.md.

Features

ペライチのデザインシステム

ライト / ダークで揃うトークン、レイアウト・コントロール・カード・表・チャートの CSS atoms、そしてレビューレールやインライン編集・表・選択・ダイアログなどのコンポーネント。

ビュー

ページ全体を担う型。User Story Mapping、UX Prototype、Slides、Task Context Board、Delegation Poker、Plain。

ボード

ビューに埋め込むことも、ページそのものにもできる視覚面。ER・ステート・シーケンス・依存関係・アーキテクチャ・マインドマップ・イベントストーミング・サンプルマッピング・ホワイトボード・カンバン。

レビューループ

操作は構造化された変更要求として記録され、コメントと一緒に Agent へ返る。質問（grill）も、コピーも、Claude への送信も同じ 1 つの下書きに載る。

Claude Artifacts

ページを Claude Artifact として公開すると、レビューを 1 クリックでその Claude セッションに返せる。テーマもビューアに合わせる。

Agent-first

Agent が解釈しやすいデータ構造と、いつ・どのページを使うかを決めるスキル。ビルドも設定も要らない。
